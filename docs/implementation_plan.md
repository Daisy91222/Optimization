# 实施计划与验收

| 阶段 | 交付 | 验收 |
|---|---|---|
| 数据 | 官方样本下载、来源标签 | 三类来源可查询，真实字段不臆造 |
| SQL | raw/dim/fact/mart、DQ、分析与复盘 | 必需表非空；关键 SQL 有注释 |
| 模型 | 时间切分 Ridge、反事实、置信分 | 指标 JSON；模型版本进入结果 |
| 优化 | 当前/贪心/CP-SAT、诊断兜底 | 推荐粒度唯一；优化场景零违规 |
| 审计 | 模拟计划/现场/照片/追溯 | 异常可在 review view 查询 |
| 产品 | Streamlit 与离线 HTML | 门店/周筛选、口径边界清晰 |
| 工程 | pytest、Makefile、文档 | 从 demo 到测试可一键复现 |
